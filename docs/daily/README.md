# Daily Work Files

Each daily file is a small execution contract. Copy `template.md` to the next available day before starting work.

Naming convention:

```text
day-01-foundation.md
day-02-schemas.md
day-03-events.md
```

A day is complete only when its acceptance criteria and tests are recorded. If work remains, keep the file active and record the blocker instead of silently moving forward.
